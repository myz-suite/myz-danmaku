🌍 MyZ Danmaku 动态多语言系统测试

📋 测试说明

这个页面验证了MyZ Danmaku扩展的动态多语言系统：

  • Chrome Web Store兼容性：使用Chrome i18n API进行商店检测
  • 运行时动态切换：使用自定义I18nManager进行实时语言切换
  • 跨组件同步：popup、content script和background之间的语言同步

🎯 核心功能验证

1. Chrome Web Store 多语言检测

状态： ✅ 已配置
Manifest： 使用 __MSG_* 占位符
目录结构： _locales/{language}/messages.json
支持语言： 中文 (zh_CN) 和英文 (en)

2. 运行时动态语言切换

核心组件： 自定义I18nManager
语言检测： 浏览器语言 + 用户偏好存储
实时更新： 语言切换时UI立即更新

3. Content Script 动态i18n

// Content script 使用动态 t() 函数，而非静态 chrome.i18n function updateDanmakuButtonText(button: HTMLButtonElement): void { button.textContent = t("danmakuButton"); // 动态获取 button.title = t("danmakuButtonTitle"); // 动态获取 button.setAttribute("aria-label", t("danmakuButtonAriaLabel")); } // 监听语言变化事件 onLanguageChange((language) => { updateContentScriptLanguage(language); // 实时更新 });

4. 跨组件语言同步

// 使用 chrome.storage 进行跨组件通信 chrome.storage.onChanged.addListener((changes, namespace) => { if (namespace === 'sync' && changes[LANGUAGE_STORAGE_KEY]) { const newLanguage = changes[LANGUAGE_STORAGE_KEY].newValue; updateContentScriptLanguage(newLanguage); } });

🔧 技术实现

混合策略 (Hybrid Approach)

// 1. Chrome Web Store 兼容性 (Manifest) { "name": "__MSG_extensionName__", // 商店检测 "description": "__MSG_extensionDescription__", "default_locale": "zh_CN" // 必需字段 } // 2. 运行时动态系统 (Custom I18nManager) const i18n = new I18nManager(); // 动态管理 i18n.t('refreshButton'); // 运行时获取 i18n.setLanguage('en'); // 动态切换 onLanguageChange((lang) => { /* 监听变化 */ });

内容脚本集成

// Content script 使用动态 t() 函数 import { t, onLanguageChange } from "./shared/i18n"; // 按钮文本动态更新 button.textContent = t("danmakuButton"); button.title = t("danmakuButtonTitle"); // 监听语言变化 onLanguageChange((language) => { updateContentScriptLanguage(language); });
